# MiniGame Platform 🎮

Веб-портал классических мини-игр с акцентом на чистый интерфейс, высокую производительность и полную автономность (Offline-first PWA).

Деплоится на Vercel как статическое/клиентское приложение без необходимости настройки внешних баз данных или переменных окружения.

---

## Особенности

* ⚡ **100% Offline-first:** Полная автономность — играйте без интернета благодаря Service Worker (PWA).
* 💾 **Локальные рекорды:** Все результаты, победы, лучшее время и очки сохраняются локально в браузере (`localStorage`).
* 🎨 **Темы оформления:** Поддержка светлой и тёмной тем с адаптивным дизайном под мобильные устройства и десктоп.
* 🧩 **Модульная архитектура:** Чистое разделение игровой логики (чистый TypeScript) и слоя отображения (React/Next.js).
* 🚀 **Нулевой бэкенд:** Не требует внешних сервисов, баз данных или API-ключей.

## Стек технологий

* **Фреймворк:** [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
* **Интерфейс:** React 19, TypeScript, [Tailwind CSS](https://tailwindcss.com/)
* **Компоненты:** [Lucide React](https://lucide.dev/), Tailwind CSS, Framer Motion
* **Состояние:** [Zustand](https://github.com/pmndrs/zustand)
* **Звук:** Web Audio API (полноценный синтез звуков без внешних файлов)
* **PWA / Оффлайн:** Service Worker + LocalStorage API

## Архитектура: как устроены игры

Каждая игра строится по строгому интерфейсу **`GameEngine<TState, TAction>`** в папке `games/<game_id>/`:
1. **Логика независима от React**: движок, генератор и валидатор написаны на чистом TypeScript.
2. **Предсказуемое состояние**: состояние изменяется через чистые функции `applyAction(state, action)`.
3. **Хук-обёртка**: React-слой подключается через хук `use<Game>()` (например, `useSudoku()`), управляющий таймером, историей ходов (Undo/Redo) и состоянием оверлея.
4. **Сохранение результатов**: при завершении партии результат автоматически фиксируется в `lib/storage/records.ts`.

## Запуск и разработка

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального сервера разработки
npm run dev
```

Приложение будет доступно по адресу: [http://localhost:3000](http://localhost:3000)

```bash
# 3. Проверка типов и линтинг
npm run lint

# 4. Продакшен-сборка
npm run build
```
